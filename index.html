Политика конфиденциальности

Приложение «График смен» — расписание рабочих смен

Разработчик: Южаков Илья Пакет: com.grafiksmen.app Платформа: Android 12+ Версия документа: 1.0 Дата: 2025 г.

1 Общие положения

Настоящая Политика конфиденциальности описывает, каким образом приложение «График смен» (далее — «Приложение») обрабатывает данные пользователей.

Приложение предназначено для составления, хранения и просмотра рабочего графика смен. Все функции работают исключительно на устройстве пользователя.

🔒 Приложение не собирает, не хранит и не передаёт персональные данные пользователей на какие-либо внешние серверы или третьим лицам.

2 Данные, которые хранятся на устройстве

Все данные, создаваемые в процессе использования Приложения, хранятся только локально на устройстве пользователя (SharedPreferences):

Данные Назначение Передача
Даты начала и окончания графика Расчёт рабочих смен Нет
Тип графика (2×2, 3×3 и др.) Автоматический расчёт Нет
Рабочие и выходные дни (ручные правки) Отображение в календаре Нет
Время и параметры напоминаний Локальные уведомления Нет
Настройки темы оформления (цвета) Внешний вид приложения Нет
Имена сотрудников (расширенная версия) Общий календарь команды Нет
Флаг режима (стандартный / расширенный) Управление функциями Нет

3 Что Приложение не собирает

Приложение не собирает и не запрашивает:

❌ Персональные данные (ФИО, дата рождения, адрес)
❌ Контактные данные (телефон, email, мессенджеры)
❌ Геолокацию и данные о местоположении
❌ Данные об устройстве (IMEI, серийный номер, MAC-адрес)
❌ Аналитику использования, статистику и метрики
❌ Рекламные идентификаторы
❌ Финансовые данные и данные банковских карт
❌ Фотографии, камеру и медиафайлы

4 Запрашиваемые разрешения

Приложение запрашивает следующие системные разрешения Android:

Разрешение Причина Данные передаются?
POST_NOTIFICATIONS Отправка напоминаний о рабочих сменах Нет
SCHEDULE_EXACT_ALARM Точное планирование времени уведомлений Нет
USE_EXACT_ALARM Точное планирование времени уведомлений Нет
RECEIVE_BOOT_COMPLETED Восстановление напоминаний после перезагрузки Нет
RECORD_AUDIO Голосовой ввод графика (по инициативе пользователя) Нет
VIBRATE Вибрация при уведомлениях Нет
INTERNET Отображение страницы политики конфиденциальности Нет
🎤 Разрешение на микрофон запрашивается только в момент, когда пользователь сам нажимает кнопку голосового ввода. Никакие аудиозаписи не сохраняются и не передаются.

5 Третьи лица и реклама

Приложение не содержит рекламы и не использует сторонние рекламные SDK (AdMob, YandexAds и др.).

Приложение не интегрировано с аналитическими сервисами (Firebase Analytics, AppMetrica, Mixpanel и др.).

Приложение не передаёт никакие данные третьим лицам, партнёрам или государственным органам (за исключением случаев, прямо предусмотренных законодательством Российской Федерации).

6 Хранение и удаление данных

Все данные хранятся в локальном хранилище приложения на устройстве пользователя.

Данные удаляются автоматически при удалении Приложения с устройства.

Пользователь может очистить все данные вручную двумя способами:

  • Через кнопку «Сброс» в самом Приложении
  • Через настройки Android: Настройки → Приложения → График смен → Хранилище → Очистить данные

Резервное копирование данных в облако отключено (android:allowBackup="false") для обеспечения конфиденциальности пользователя.

7 Защита данных детей

Приложение имеет возрастной рейтинг 0+ и не предназначено для сбора данных о лицах младше 18 лет.

Приложение не собирает никаких данных ни о детях, ни о взрослых пользователях.

8 Безопасность

Поскольку Приложение не передаёт данные за пределы устройства, риск утечки данных через сетевые каналы полностью исключён.

Сетевой трафик Приложения ограничен политикой Network Security Config — разрешён только HTTPS, HTTP-трафик запрещён.

Безопасность данных на самом устройстве обеспечивается стандартными механизмами защиты Android.

9 Изменения политики

Разработчик оставляет за собой право вносить изменения в настоящую Политику конфиденциальности.

При существенных изменениях пользователи будут уведомлены через обновление Приложения в магазине приложений.

Актуальная версия Политики всегда доступна по постоянной ссылке, указанной в описании Приложения в магазине.
